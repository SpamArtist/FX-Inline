FAQ

Does FX Inline replace checkout localization?

No. FX Inline is for pricing-page comprehension before checkout. Checkout localization still belongs in your payment or billing stack.

Will the local estimate be exact?

It should be presented as an estimate. The original price remains visible and remains the source of truth.

How automatic is page detection?

FX Inline uses conservative detection and selector-aware rendering. Unknown structures should fail closed rather than showing confusing pricing.

What happens if the pricing page changes?

Deployments should include QA notes, health checks, and a rollback path so the page can fail safely instead of showing confusing pricing.
