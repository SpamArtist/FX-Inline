Buyer questions

Clear boundaries make the offer easier to trust.

Does FX Inline replace checkout localization?

No. FX Inline is for pricing-page comprehension before checkout. Checkout localization still belongs in your payment or billing stack.

Will the local estimate be exact?

It should be presented as an estimate. The original price remains visible and remains the source of truth.

Can it work on every page automatically?

The commercial pilot should not promise arbitrary-site perfection. It starts with a known pricing page, selector review, and explicit fallback behavior.

What happens if the pricing page changes?

The pilot should include QA notes, health checks, and a rollback path so the page can fail safely instead of showing confusing pricing.
