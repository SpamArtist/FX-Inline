Quick Reference

JavaScript for FX Inline

Use this sheet while reading the extension. It compresses the JavaScript ideas that show up repeatedly in this repository.

1. Modules tell you where logic lives

Each file is a module. Files share logic with export and consume it with import. 

import { getRates } from "@/utils/rates/index";
export async function getUserSettings() { ... }

Reading trick: start at the imports, then scan exported functions. That gives you the file's dependencies and responsibilities fast.

2. Functions are the main unit of behavior

Most files exist to define small functions that transform data, schedule work, or connect browser APIs. 

function logWelcomePageError(error) {
  console.warn("...", error);
}

When a function only wraps another function call, it usually exists to name a responsibility or isolate an edge case.

3. Objects hold named state

JavaScript objects are everywhere in this repo: settings, alarm options, browser event payloads, and reducer actions. 

{
  periodInMinutes: 30,
  forceRefresh: true
}

Reading trick: object keys are often better clues than variable names because they reveal the contract expected by another function or API.

4. Arrays drive batch work

Arrays usually mean “a list we will map, filter, loop over, or pass into a helper like Promise.all.” 

const VALID_CURRENCY_CODES = new Set(
  Object.values(CurrencyCode),
);

Common reading pattern: if you see map, ask “what list is being transformed?” If you see Object.entries, ask “which object is being turned into key/value pairs?”

5. async/await marks delayed work

If a function is async, it returns a promise. await pauses inside that function until the promise settles. 

async function initializeRateRefresh(forceRefresh = false) {
  await Promise.all([
    scheduleRateRefreshAlarm(),
    getRates({ forceRefresh }),
  ]);
}

Reading trick: draw a box around every await. Those are the points where control flow can pause or fail.

6. WXT entrypoints are runtime borders

Files under apps/extension/entrypoints/ are where the extension actually starts running: background, popup, options, content. 

export default defineContentScript({
  matches: ["<all_urls>"],
  main(ctx) {
    createContentActivationController(ctx).start();
  },
});

Reading trick: if you want to know “where does this feature begin?”, start in an entrypoint, then follow imports downward into utilities and packages.

7. Preact hooks manage UI state

In UI files, state changes usually happen with hooks like useState, useEffect, and callback-driven reducers. 

const [rateSnapshot, setRateSnapshot] = useState(null);

useEffect(() => {
  async function loadSettingsAndRates() { ... }
  loadSettingsAndRates();
}, []);

Reading trick: find state declarations first, then effects, then event handlers or dispatch functions.
