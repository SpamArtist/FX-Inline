# Mission: JavaScript for FX Inline

## Why
Learn enough JavaScript to read, navigate, and safely modify this WXT-based browser extension without guessing. The goal is not generic JS mastery first; it is practical fluency with the language features and runtime boundaries this repo uses every day.

## Success looks like
- Trace how a feature moves through entrypoints, utility modules, hooks, and packages in this repository.
- Read imports, exports, async flows, and state updates in the extension without getting lost.
- Make small, focused changes to extension behavior and understand where to test them.

## Constraints
- The learner already knows basic HTML and CSS.
- Teaching should stay grounded in this repository instead of drifting into generic frontend theory.
- Early lessons should prefer small, fast wins over broad language coverage.

## Out of scope
- Deep computer-science theory.
- Advanced framework internals beyond what is needed to understand this repo.
- Full TypeScript mastery before core JavaScript fluency.
